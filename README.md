# global-property-purchase-prediction
End-to-end machine learning project for predicting global property purchase decisions using Logistic Regression, EDA, feature engineering, and hyperparameter tuning.

## Project Roadmap

### Phase 1
- Exploratory Data Analysis
- Logistic Regression Baseline
- Hyperparameter Tuning

### Phase 2 (Planned)
- Decision Tree
- Random Forest
- XGBoost
- Model Comparison Dashboard

### Phase 3 (Planned)
- Streamlit Deployment
- Real-time Prediction Interface
- SHAP Explainability
